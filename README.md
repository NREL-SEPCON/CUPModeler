# CUP Modeler

This repository contains modeling scripts and an interface developed to support the work described in:

**Alherech M., Beckham G.T., & Choi H. (2025). Implementation and Evaluation of Multi-Dual Mode Counter-Current Chromatography in the CUP Modeler Software. *Journal of Chromatography A, 1760, 466265*. [https://doi.org/10.1016/j.chroma.2025.466265](https://doi.org/10.1016/j.chroma.2025.466265)**

## Getting Started

Clone the repository:

```bash
git clone https://github.com/<your-org-or-username>/<your-repo-name>.git
```

Either run the script with Python (>=3.9 recommended):

```bash
python main.py
```

Or run the appropriate installer file for your operating system to generate an executable (instructions included in the Installer directory)
